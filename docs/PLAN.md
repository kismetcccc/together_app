## UI 改版 · 2026-10-22

暖白与深紫配色；原生叠放照片插画；首页主视觉与相册统计；精简登录操作；更紧凑的照片网格与底部导航。插画由 React Native View 绘制，不依赖外部图片、WebView 或新增第三方库。

执行顺序：现状检查 → 公共视觉规范 → 登录/首页/相册/导航 → 类型与回归测试 → 手机尺寸辅助检查 → 提交仓库。全部完成。

验证：npm run verify（后端 13 项 + 客户端 6 项）；Expo Android/iOS/Web 导出通过；辅助预览使用隔离账号登录、打开相册、显示私有图片；390px 与 320px 检查无横向溢出。这仍不是原生真机验收。

新版预览：docs/screenshots/redesign-home.jpg、redesign-album.jpg。

### 字体与渐变修订

根据反馈改为更轻的系统字体、25px / 500 主标题、30px / 300 封面标题，移除厚重的深色封面和照片叠卡。首页、登录页与相册封面使用 React Native 0.88 原生 backgroundImage 的粉紫—蜜桃渐变；相册封面保留已鉴权的原照片小预览。原照片数据不变。新增依赖：无。

19 项回归测试通过；最终渐变版本 Android/iOS/Web 导出通过。手机尺寸辅助预览已刷新。真机渐变表现仍需在安装包中验收。

GitHub 推送两次因自动审批服务超时未执行，本次修改已在本地保存；未把远端同步标记为完成。

### 极简照片墙修订 · 当前设计

按最新反馈替换之前的渐变方案：纯白背景、黑灰文字；顶部仅「照片」与创建相册 +；删除 Banner、装饰封面和渐变组件。首页直接展示有权限访问的真实照片，按原图宽高分为两列 Masonry，4px 间距；底部无边框分类 Tab 使用细下划线。点照片进入所属相册，空相册保留上传入口。

执行：清理旧组件 → 原生照片墙与尺寸回调 → 类型检查 → 回归与导出 → 手机尺寸辅助验收。类型检查和 Web 辅助预览构建已通过；390px 下实际检查分类切换、空状态、照片进入相册、加号打开创建表单通过。完整 npm run verify 与双平台导出连续两次因自动审批服务超时未执行，不能算通过。原账号、图片和共享权限保持原有接口。

首页明确为相册列表：21px 半粗标题、44px 浅灰圆形创建按钮；顶部可横向滚动的黑白胶囊分类；全宽轻阴影卡片显示真实封面、名称、照片数、成员数与更新时间。底部主导航留在安全区域底部，选中黑色、未选中灰色。
